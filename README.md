# 鼠鼠小助手 ShuShu Tweaks

一个 SillyTavern 第三方扩展，解决两个日常痛点：

1. **续写（Continue）后思维链暴露 / 格式变乱**
2. **导入角色卡时总是新建副本，无法更新原有角色**

---

## 功能一：思维链收纳（Thinking Shield）

三层防护，把 `<think>` 等思维链内容从正文转移到酒馆原生的折叠思维链块
（`extra.reasoning`）：

| 层级 | 机制 | 作用 |
|---|---|---|
| 生成前 | Prompt 拦截器（`generate_interceptor`） | 任何生成（普通 / 续写 / 重 roll / swipe）发起前清洗聊天记录，模型拿到的 prompt 永远不带思维链 —— 根治续写把思维链吐回正文、格式被冲乱的问题 |
| 显示时 | 消息格式化钩子（`messageFormatter`，在正则规则之前） | 显示层兜底剥离思维链标签，包括流式输出时未闭合的半截标签，屏幕上一个字符都不会闪出来 |
| 存储层 | `MESSAGE_RECEIVED` / `GENERATION_ENDED` / `CHAT_CHANGED` 事件 | 生成结束、收到消息、切换聊天时把存量思维链收纳进 `extra.reasoning` 并保存，历史聊天里的旧数据也会被清理；清理后自动重绘界面 |

> **重要：思维链不会被删除。** 所有内容都保存在酒馆原生的"思考"折叠块
> （`extra.reasoning`）里——点开消息上方的折叠块即可查看，展开后还能
> 复制和编辑。收纳后插件会自动重绘聊天界面，让折叠块显示出来。
>
> 如果你希望模型续写时仍能参考之前的思考内容：酒馆自带
> "高级格式化（Advanced Formatting）→ Reasoning → Add to Prompts"
> 开关，开启后折叠块里的内容会按你的设置送回 prompt，与本插件完全兼容。

和显示层正则的本质区别：正则只是"给人眼打马赛克"，原始消息里思维链还在；
本扩展是在**数据层**把思维链移进它该待的位置，续写、重渲染、换设备都不会再暴露。

## 功能二：角色卡导入同名检测

通过"导入角色"按钮选择 **PNG / JSON** 角色卡时：

1. 插件先在浏览器端解析卡片数据（PNG 的 `tEXt`/`iTXt`/`zTXt` 中的 `chara` 块）；
2. 若已有**同名角色**，弹窗询问：
   - **更新原角色** → 用新卡内容更新原有角色（走 `/api/characters/edit`）；
   - **新建副本** → 仍然按原生流程新建副本；
   - **关闭弹窗 / ESC** → 取消导入；
3. 更新时会**保留**：原角色的聊天记录绑定、收藏状态、世界书（Lorebook）链接；
   本地手动标签与新卡标签取并集；
4. 头像默认不替换，可在设置中开启"更新时同时替换头像图片"。

> 注意：目前只拦截"导入角色"按钮的文件选择。拖拽到页面导入、URL 导入、
> 群聊角色导入仍走原生流程。

## 安装

把整个 `SillyTavern-TavernTweaks` 文件夹复制到：

```
SillyTavern/public/scripts/extensions/third-party/
```

然后刷新酒馆页面，在"扩展（Extensions）"面板确认"鼠鼠小助手 ShuShu Tweaks"已启用。

扩展设置入口：扩展面板 → 鼠鼠小助手 ShuShu Tweaks。

## 设置项

| 设置 | 默认 | 说明 |
|---|---|---|
| 思维链收纳 | 开 | 总开关 |
| 加载聊天时清理历史消息 | 开 | 切换/打开聊天时把历史里的思维链也收纳掉 |
| 思维链标签 | `think,thinking,thought` | 需要收纳的标签名，逗号分隔，可自定义 |
| 导入检测同名角色 | 开 | 导入时检测是否已有同名角色 |
| 同名时的动作 | 每次询问 | 每次询问 / 总是更新原角色 / 总是新建副本 |
| 更新时替换头像 | 关 | 勾选后更新同名角色会用新卡的图片替换头像（仅 PNG 卡） |

## 兼容性

- 需要 SillyTavern **1.12.0+**（1.13+ 才能启用显示层钩子；旧版本存储层与
  拦截器防护仍然有效）。
- 与显示层正则（Regex 扩展）不冲突：本扩展在正则规则**之前**运行，
  已被收纳的思维链不会再出现在显示文本里。
